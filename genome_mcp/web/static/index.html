Use these tools from Claude Desktop (MCP)

Install the package, then add this to Claude Desktop → Settings → Developer → Edit Config, and restart. Claude will list 9 genome tools and call them when you ask.

{ "mcpServers": { "genome": { "command": "/full/path/to/.venv/bin/genome-mcp", "args": ["serve", "--vcf", "/full/path/to/your_sample.vcf"] } } }
